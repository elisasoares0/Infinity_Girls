Pesquisa UX - app de monitoramento de saúde para astronautas
Arquivos para importar no FigJam

COMO IMPORTAR
1. Abra um quadro no FigJam.
2. Arraste cada arquivo .csv para o quadro (ou use o menu principal > Arquivo > Importar).
   Cada CSV vira uma tabela editável.
3. Arraste a imagem 06b-diagrama-fluxo-de-dados.png para o quadro, ao lado da tabela 06.
4. Sugestão: crie uma seção (Section) para cada número de arquivo e organize da esquerda
   para a direita: 01 objetivo -> 13 fontes.

  direto no FigJam: dados colados de planilhas também viram tabela.
